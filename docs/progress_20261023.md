# 2026-10-23 · `su` 全链路打通（3.16.22 → 3.16.27）

设备：荣耀 Magic6 Pro（BVL-AN16），MagicOS 10.0.0.170 / Android 16，内核 `6.1.157-android14-11-g7d3922fade43`
结论：**aShell 本地模式（uid 10244）里 `su -c id` → `uid=0(root) context=u:r:ksu:s0`**

---

## 1. 最终可用的链路

```
shell: access("/system/bin/su")
  ↓ kprobe __arm64_sys_faccessat / newfstatat
    · 参数要从 ((struct pt_regs *)x0)->regs[1] 取，不是 x1
    · 读之前砍掉 MTE 高字节标签
  ↓ 命中 → 把路径参数指到 App lib 目录里的 ksud 副本（用户栈下方）
shell: 预检通过
  ↓ execve("/system/bin/su")
  ↓ kprobe do_execveat_common（读的是内核 fn->name，不受 MTE 影响）
  ↓ 原地覆盖 fn->name → 同上那份 ksud 副本
  ↓ begin_new_exec：su_cred=2 → task_work_add(TWA_RESUME)
  ↓ exit_to_user_mode 前 escape_with_root_profile()
      · setup_selinux(root profile) → u:r:ksu:s0
      · alloc_uid / set_cred_ucounts
ksud: 以 uid=0 + ksu 域启动 → ioctl 走通
```

## 2. 六个真因（按发现顺序，每个都单独卡了一轮）

| # | 现象 | 真因 | 修法 |
|---|---|---|---|
| 1 | 模块 insmod 失败，模块不 Live | `__attribute__((weak))` 走 GOT，产生不支持的重定位 | 改普通 `extern`；`ko_check.py` 加第四道门扫 `.rela` |
| 2 | `su-check` 0 次命中 | 调用方是 root shell（uid 0），门控只放行 allowlist/管理器 | 门控放行 `u == 0` |
| 3 | 钩子 rc=0 却从不命中 | `strncpy_from_user_nofault()` 在本机恒返回 -EFAULT | 改 `copy_from_user_nofault()` 手工截断 |
| 4 | 换完还是 `<unreadable>` | `__arm64_sys_*` 是只收 `struct pt_regs *` 的包装函数，x1 是垃圾 | 按符号名分流：`__arm64_sys_` 前缀 → 再解一层 `regs->regs[0]` |
| 5 | `adb shell` 读得出、App 读不出 | App 指针带 MTE 标签（`ptr=b400006f…`），`access_ok()` 判越界 | 读前 `& ~0xFF00000000000000UL` |
| 6 | `id` 是 root 但写不了 sysfs | 只换 uid 不换 SELinux 域（`u:r:untrusted_app:s0`） | `su_cred=2`：task_work + `escape_with_root_profile()` |

第 6 条是最关键的一条：**uid=0 不等于 root**。`/sys/module/.../parameters/*` 是 `u:object_r:sysfs:s0`，Enforcing 下 App 域写不进去，所以“提权了却什么都做不了”。

## 3. 真机证据（3.16.27 / r41）

```

ksu-dbg SU-EXEC uid=10244 pid=30168 n=/system/bin/su
ksu: su-redirect uid=10244 → …/com.dsh.ppgroot-…/lib/arm64/libksu_su.so
ksu: su-twerk escape pid=30168 rc=0    ×10

su-check 4 · su-redirect 4 · su-twerk 10 · ksu ioctl 1955
avc: denied 0 · Kernel panic 0 · Oops 0
```

MTE 证据（同一份 ko，同一条钩子）：

```
uid=2000（adb shell）   ptr=0000006f…          → 路径可读
uid=10244（App）        ptr=b400006fe200f6f8   → 砍掉 b4 后可读
```

## 4. 运行时开关

| 参数 | 取值 |
|---|---|
| `su_cred` | 0 只重定向 / 1 手工改 cred（uid 0，域不变）/ **2 task_work 换域（当前）** |
| `su_check` | 1 开 access/stat 伪装（默认） |
| `su_dbg` + `su_dbg_uid` | 调试：对该 uid 的每次 access/stat 打日志（含 ptr） |
| `su_mgr_appid` | 放行管理器自身 |

marker（`/data/local/tmp/route/m6/`）：`SU_CRED_TW` → `su_cred=2`；`NO_SUCRED` → 0；`SU_CHECK_DBG=<uid>` → 打开调试。

参数只能由 loader 在提权时写（`0644 root` + Enforcing）。

## 5. 已知限制

1. **提权成功后按钮变灰，不能二次提权** → 换 ko 必须重启重来越狱。所以能用运行时参数解决的一律不重编。
2. `ksud unload` 必 panic，不能靠卸载重载换参数。
3 `.github` Actions 每轮全量编译约 25 分钟，三份 ko 并行。
4. 桌面 APK 每轮都会新增，需要阶段性归档（见 `D:\githubs\m6p\10-修复版APK\3.16系列\`）。

## 6. 打包四道门（`D:\ksu-build\ko_check.py`）

```
① UND 全在 next_sym_addr_uapi5.txt 内    拦过 jiffies / ksu_manager_appid
② vermagic 与内核一致                    —

```
